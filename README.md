# theprivedcoders
Healthcare Emergency System
Guided Emergency Aid App

A simple, fast, and user-friendly first aid quick guide web app designed to help users respond effectively during emergency situations. The app provides step-by-step instructions for common first aid scenarios, ensuring guidance is available even under pressure.

🚀 Features

✅ Quick access to first aid steps for common emergencies (bleeding, burns, CPR, choking, etc.)

✅ Step-by-step instructions for clarity under stress

✅ Mobile-friendly, lightweight design for use anywhere

✅ Search functionality to find help fast

✅ Simple, clean interface with icons for easy navigation

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript
